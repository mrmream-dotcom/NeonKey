Security+ acronym list

Study guideSecurity+

Security+ uses a lot of acronyms. Here are the common ones in plain language, grouped by the domain where they come up most. Use your browser’s find (Ctrl/Cmd+F) to jump to one. CompTIA publishes its full official acronym list with the exam objectives.

Domain 1: General Security Concepts

AcronymStands forWhat it means
AAAAuthentication, Authorization, and AccountingVerify identity, grant permissions, and log actions.
CIAConfidentiality, Integrity, AvailabilityCore goals of information security.
MFAMultifactor AuthenticationRequires at least two distinct authentication factor categories.
SSOSingle Sign-OnOne login provides access to multiple connected services.
PKIPublic Key InfrastructureSystem of certificates, keys, and trust authorities.
CACertificate AuthorityIssues and signs trusted digital certificates.
CSRCertificate Signing RequestRequest containing certificate identity and public key information.
CRLCertificate Revocation ListPublished list of revoked certificates.
OCSPOnline Certificate Status ProtocolQueries whether a certificate has been revoked.
AESAdvanced Encryption StandardWidely used symmetric block cipher.
RSARivest–Shamir–AdlemanPublic-key cryptography algorithm used for signing and encryption.
ECCElliptic Curve CryptographyPublic-key cryptography using elliptic-curve mathematics.
HMACHash-based Message Authentication CodeVerifies message integrity and authenticity with a shared secret.
SHASecure Hash AlgorithmFamily of cryptographic hashing functions.
TLSTransport Layer SecurityProtects communications in transit.
TPMTrusted Platform ModuleHardware-backed security for keys and device integrity.
HSMHardware Security ModuleTamper-resistant device protecting cryptographic keys.
PFSPerfect Forward SecrecyPast sessions stay protected if a long-term key is later exposed.
PSKPre-Shared KeySecret agreed upon before an authenticated exchange.
RBACRole-Based Access ControlPermissions assigned according to job roles.
ABACAttribute-Based Access ControlAccess decisions based on user, resource, and context attributes.
DACDiscretionary Access ControlResource owner determines access permissions.
MACMandatory Access ControlSystem-enforced access based on labels and clearances.
FDEFull-Disk EncryptionEncrypts an entire storage drive.
PIVPersonal Identity VerificationUS government smart-card credential standard for identity verification.
TOTPTime-based One-Time PasswordTemporary code derived from a secret and time.
HOTPHMAC-based One-Time PasswordCounter-based one-time authentication code.
FIDOFast Identity OnlineStandards for phishing-resistant modern authentication.

Domain 2: Threats, Vulnerabilities, and Mitigations

AcronymStands forWhat it means
APTAdvanced Persistent ThreatSophisticated attacker conducting sustained, targeted activity.
CVECommon Vulnerabilities and ExposuresIdentifier assigned to a publicly disclosed vulnerability.
CVSSCommon Vulnerability Scoring SystemFramework scoring vulnerability severity.
CWECommon Weakness EnumerationCatalog of classes of software and hardware weaknesses.
DDoSDistributed Denial of ServiceTraffic from multiple systems overwhelms a target.
DoSDenial of ServiceAttack degrades or prevents service availability.
SQLiSQL InjectionMalicious input changes database queries.
XSSCross-Site ScriptingInjected script executes in a user's browser.
CSRFCross-Site Request ForgeryTricks an authenticated browser into making an unwanted request.
SSRFServer-Side Request ForgeryMakes a server issue requests chosen by an attacker.
RCERemote Code ExecutionAbility to execute code on another system.
RATRemote Access TrojanMalware allowing unauthorized remote control.
IOCIndicator of CompromiseObservable clue suggesting malicious activity.
IOAIndicator of AttackEvidence of suspicious attacker behavior or technique.
MITMMan-in-the-Middle (on-path attack)Attacker sits between two parties to read or change traffic. CompTIA now calls this an on-path attack.
BECBusiness Email CompromiseSocial-engineering fraud through trusted-looking business messages.
OSINTOpen-Source IntelligenceInformation gathered from publicly available sources.
ASLRAddress Space Layout RandomizationRandomizes memory locations to impede exploitation.
DEPData Execution PreventionPrevents execution in memory regions marked as data.
EDREndpoint Detection and ResponseEndpoint telemetry, detection, investigation, and response.
AVAntivirusDetects and blocks known or suspicious malicious software.
NIDSNetwork Intrusion Detection SystemMonitors network traffic for suspicious activity.
NIPSNetwork Intrusion Prevention SystemDetects and actively blocks malicious network traffic.
WAFWeb Application FirewallFilters HTTP traffic to protect web applications.
SASTStatic Application Security TestingAnalyzes source or binary code without running it.
DASTDynamic Application Security TestingTests running applications for weaknesses.
C2Command and ControlAttacker's channel for managing compromised systems.
ATT&CKAdversarial Tactics, Techniques, and Common KnowledgeMITRE knowledge base of observed adversary behaviors.

Domain 3: Security Architecture

AcronymStands forWhat it means
DMZDemilitarized Zone (screened subnet)Isolated network segment for internet-facing systems. Current CompTIA wording is screened subnet.
VLANVirtual Local Area NetworkLogical segmentation of a switched network.
VPNVirtual Private NetworkProtected logical connection across another network.
IPsecInternet Protocol SecurityProtocol suite securing IP traffic.
IKEInternet Key ExchangeNegotiates secure associations and keys for IPsec.
DNSDomain Name SystemResolves domain names to network records.
DNSSECDomain Name System Security ExtensionsAuthenticates DNS responses with digital signatures.
DHCPDynamic Host Configuration ProtocolAutomatically distributes IP settings to hosts.
NATNetwork Address TranslationTranslates network addresses between domains.
SDNSoftware-Defined NetworkingSeparates control and forwarding for programmable networks.
SASESecure Access Service EdgeCombines network connectivity with cloud-delivered security.
ZTNAZero Trust Network AccessGrants application access through identity-aware verification.
CASBCloud Access Security BrokerEnforces security policies for cloud service usage.
CSPCloud Service ProviderVendor supplying cloud infrastructure or services.
IaaSInfrastructure as a ServiceProvider supplies compute, storage, and networking resources.
PaaSPlatform as a ServiceProvider supplies managed application runtime and development platform.
SaaSSoftware as a ServiceApplication delivered and operated by a provider.
VDIVirtual Desktop InfrastructureDesktop environments hosted centrally.
BYODBring Your Own DevicePersonal devices are allowed for organizational work.
COPECorporate Owned, Personally EnabledOrganization-owned device permitting personal use.
MDMMobile Device ManagementManages configuration and security of mobile devices.
MTDMobile Threat DefenseDetects threats on mobile endpoints.
SDLCSoftware Development Life CyclePhases for developing and maintaining software.
CI/CDContinuous Integration / Continuous DeliveryAutomated processes to build, test, and release changes.
IaCInfrastructure as CodeManages infrastructure through versioned configuration code.
RTORecovery Time ObjectiveMaximum acceptable time to restore a service.
RPORecovery Point ObjectiveMaximum acceptable data loss measured in time.
UPSUninterruptible Power SupplyProvides short-term backup electrical power.
HVACHeating, Ventilation, and Air ConditioningControls building temperature and airflow.

Domain 4: Security Operations

AcronymStands forWhat it means
SOCSecurity Operations CenterTeam or facility monitoring and responding to security events.
SIEMSecurity Information and Event ManagementAggregates and correlates logs for detection and investigation.
SOARSecurity Orchestration, Automation, and ResponseCoordinates and automates security-response workflows.
XDRExtended Detection and ResponseCorrelates detection data across multiple security layers.
IDSIntrusion Detection SystemAlerts on suspected malicious activity.
IPSIntrusion Prevention SystemDetects and blocks prohibited traffic or behavior.
NGFWNext-Generation FirewallFirewall with application awareness and advanced inspection.
NACNetwork Access ControlEnforces device or user access requirements on networks.
DLPData Loss PreventionDetects and restricts unauthorized sensitive-data movement.
IAMIdentity and Access ManagementManages identities, authentication, and access rights.
PAMPrivileged Access ManagementControls, monitors, and secures privileged accounts.
LDAPLightweight Directory Access ProtocolQueries and manages directory information.
SAMLSecurity Assertion Markup LanguageExchanges identity assertions for federation and SSO.
OAuthOpen AuthorizationDelegates limited access to resources without sharing passwords.
OIDCOpenID ConnectAuthentication layer built on OAuth 2.0.
RADIUSRemote Authentication Dial-In User ServiceCentralized authentication and accounting for network access.
TACACS+Terminal Access Controller Access-Control System PlusAAA protocol often used for network device administration.
SSHSecure ShellEncrypted remote command-line access.
RDPRemote Desktop ProtocolRemote graphical desktop connection.
SNMPSimple Network Management ProtocolMonitors and manages network devices.
NTPNetwork Time ProtocolSynchronizes device clocks.
HTTPHypertext Transfer ProtocolApplication protocol used for web traffic.
HTTPSHypertext Transfer Protocol SecureHTTP transmitted over TLS.
SMTPSimple Mail Transfer ProtocolTransfers outgoing email between servers.
SPFSender Policy FrameworkDNS policy listing permitted email senders.
DKIMDomainKeys Identified MailCryptographically signs mail to validate sending domains.
DMARCDomain-based Message Authentication, Reporting, and ConformanceEmail-domain policy coordinating SPF/DKIM alignment and reporting.
CIRTComputer Incident Response TeamGroup coordinating cyber incident handling.
IRIncident ResponseProcess of detecting, containing, and recovering from incidents.
DFIRDigital Forensics and Incident ResponseInvestigating digital evidence and managing incidents.
PCAPPacket CaptureRecorded network packets for troubleshooting and investigation.
FIMFile Integrity MonitoringDetects unexpected file changes.
SCAPSecurity Content Automation ProtocolStandards for automated security configuration checks.
STIXStructured Threat Information ExpressionStructured format for cyber threat intelligence.
TAXIITrusted Automated Exchange of Intelligence InformationProtocol for exchanging cyber threat intelligence.

Domain 5: Security Program Management and Oversight

AcronymStands forWhat it means
GRCGovernance, Risk, and ComplianceFramework aligning security oversight, risks, and obligations.
BIABusiness Impact AnalysisIdentifies critical operations and impacts of disruption.
BCPBusiness Continuity PlanMaintains essential operations during disruptions.
DRPDisaster Recovery PlanRestores systems and services after disruption.
COOPContinuity of Operations PlanMaintains mission-essential functions during emergencies.
SLESingle Loss ExpectancyExpected cost from one realized risk event.
AROAnnualized Rate of OccurrenceExpected frequency of a risk event per year.
ALEAnnualized Loss ExpectancyEstimated annual loss: SLE multiplied by ARO.
MTTRMean Time to RepairAverage time required to repair a failed component.
MTBFMean Time Between FailuresAverage operating time between repairable failures.
MTTFMean Time to FailureExpected time until a nonrepairable item fails.
NDANon-Disclosure AgreementContract requiring confidentiality.
SLAService Level AgreementDefines expected service performance and obligations.
MOUMemorandum of UnderstandingDocuments shared intentions between parties.
MOAMemorandum of AgreementDocuments agreed responsibilities between parties.
AUPAcceptable Use PolicyDefines permitted use of systems and networks.
PIIPersonally Identifiable InformationData that identifies or can identify an individual.
PHIProtected Health InformationSensitive health information protected by applicable rules.
GDPRGeneral Data Protection RegulationEuropean Union personal-data protection law.
PCI DSSPayment Card Industry Data Security StandardIndustry security requirements for cardholder data.
HIPAAHealth Insurance Portability and Accountability ActUS law establishing requirements for protected health information.
DPOData Protection OfficerPerson overseeing organizational data-protection obligations.
RACIResponsible, Accountable, Consulted, InformedMatrix assigning roles for a task or decision.
KPIKey Performance IndicatorMetric tracking performance against an objective.
KRIKey Risk IndicatorMetric indicating changing risk exposure.
ROIReturn on InvestmentBenefit compared with cost of an investment.
