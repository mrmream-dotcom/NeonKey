Security+ acronym list

Study guideSecurity+

Security+ uses a lot of acronyms. Here are the ones on CompTIA’s official SY0-801 acronym list, in plain language, grouped by the domain where they come up most. Use your browser’s find (Ctrl/Cmd+F) to jump to one. CompTIA publishes the official list with the exam objectives.

Domain 1: General Security Concepts

AcronymStands forWhat it means
AAAAuthentication, Authorization, and AccountingVerify identity, grant permissions, and log actions.
CABChange Advisory BoardGroup that reviews and approves proposed changes.
CIAConfidentiality, Integrity, and AvailabilityCore goals of information security.
CRLCertificate Revocation ListPublished list of revoked certificates.
CSRCertificate Signing RequestRequest containing certificate identity and public key information.
OCSPOnline Certificate Status ProtocolQueries whether a certificate has been revoked.
PKIPublic Key InfrastructureSystem of certificates, keys, and trust authorities.
SOPStandard Operating ProcedureDocumented, step-by-step way to do a routine task.
TLSTransport Layer SecurityProtects communications in transit.

Domain 2: Threats, Vulnerabilities, and Attacks

AcronymStands forWhat it means
AIArtificial IntelligenceSoftware that learns from data to make predictions or generate content.
APTAdvanced Persistent ThreatSophisticated attacker conducting sustained, targeted activity.
CAPTCHACompletely Automated Public Turing test to tell Computers and Humans ApartChallenge meant to tell people from bots; can be faked or abused in attacks.
CVECommon Vulnerabilities and ExposuresIdentifier assigned to a publicly disclosed vulnerability.
CVSSCommon Vulnerability Scoring SystemFramework scoring vulnerability severity.
CWECommon Weakness EnumerationCatalog of classes of software and hardware weaknesses.
DDoSDistributed Denial of ServiceTraffic from multiple systems overwhelms a target.
DoSDenial of ServiceAttack degrades or prevents service availability.
LLMLarge Language ModelAI model trained on huge amounts of text; can be targeted by prompt injection.
NFCNear-field CommunicationVery short-range wireless used for tap-to-pay and badges.
NVDNational Vulnerability DatabaseUS government database of CVEs with severity details.
OSOperating SystemCore software that runs a computer, like Windows or Linux.
OTOperational TechnologySystems that control physical processes, like factories and utilities.
PDFPortable Document FormatsDocument format that can carry malicious content as an attachment.
QRQuick ResponseScannable code; a malicious one can lead to a phishing site (quishing).
RCSRich Communication ServicesModern text messaging standard; a path for message-based attacks.
RFRadio FrequencyWireless signals that can be intercepted or jammed.
RTFRich Text FormatDocument format that can carry malicious content as an attachment.
SMSShort Message ServiceText messaging; the channel for smishing.
SQLStructured Query LanguageDatabase language; the target of SQL injection.
TOCTime-of-checkWhen a value is checked; a race condition exploits the gap before use.
TOUTime-of-useWhen a checked value is actually used; see time-of-check.
USBUniversal Serial BusCommon device port; malicious USB drives are an attack vector.
VNCVirtual Network ComputingRemote desktop tool; an exposed one is a remote access risk.

Domain 3: Security Architecture

AcronymStands forWhat it means
BIOSBasic Input/Output SystemFirmware that starts a computer before the operating system loads.
gMSAGroup Managed Service AccountWindows service account whose password rotates automatically.
IaCInfrastructure as CodeManages infrastructure through versioned configuration code.
IPSecInternet Protocol SecurityProtocol suite securing IP traffic.
LANLocal Area NetworkNetwork covering one building or site.
RPORecovery Point ObjectiveMaximum acceptable data loss measured in time.
RPSRedundant Power SupplySecond power supply that takes over if the first fails.
RTORecovery Time ObjectiveMaximum acceptable time to restore a service.
SaaSSoftware as a ServiceApplication delivered and operated by a provider.
SSESecurity Service EdgeCloud-delivered security controls between users and the apps they use.
UPSUninterruptible Power SupplyProvides short-term backup electrical power.
VPNVirtual Private NetworkProtected logical connection across another network.
MTBFMean Time Between FailuresAverage operating time between repairable failures.
MTTRMean Time to RepairAverage time required to repair a failed component.

Domain 4: Security Operations

AcronymStands forWhat it means
BIMIBrand Indicators for Message IdentificationShows a verified brand logo on mail that passes DMARC.
CI/CDContinuous Integration and Continuous DeploymentAutomated processes to build, test, and release changes.
CSPMCloud Security Posture ManagementFinds risky settings in cloud accounts.
DHCPDynamic Host Configuration ProtocolAutomatically distributes IP settings to hosts.
DKIMDomainKeys Identified MailCryptographically signs mail to validate sending domains.
DLPData Loss PreventionDetects and restricts unauthorized sensitive-data movement.
DMARCDomain-based Message Authentication, Reporting, and ConformanceEmail-domain policy coordinating SPF/DKIM alignment and reporting.
DNSDomain Name SystemResolves domain names to network records.
EDREndpoint Detection and ResponseEndpoint telemetry, detection, investigation, and response.
GBICGigabit Interface ConverterSwappable module that connects a network port to fiber or copper.
HIDSHost-based Intrusion Detection SystemWatches one host for suspicious activity and alerts.
HIPSHost-based Intrusion Prevention SystemWatches one host and blocks suspicious activity.
HRHuman ResourcesDepartment often involved in insider investigations and account changes.
IDSIntrusion Detection SystemAlerts on suspected malicious activity.
IPInternet ProtocolHow devices are addressed and reached on a network.
IPFIXInternet Protocol Flow Information ExportStandard for exporting flow records (who talked to whom).
IPSIntrusion Prevention SystemDetects and blocks prohibited traffic or behavior.
LDAPLightweight Directory Access ProtocolQueries and manages directory information.
MDMMobile Device ManagementManages configuration and security of mobile devices.
MFAMultifactor AuthenticationRequires at least two distinct authentication factor categories.
NICNetwork Interface CardHardware that connects a device to a network.
NIDSNetwork-based Intrusion Detection SystemMonitors network traffic for suspicious activity.
NIPSNetwork-based Intrusion Prevention SystemDetects and actively blocks malicious network traffic.
OAuthOpen AuthorizationDelegates limited access to resources without sharing passwords.
OTPOne-time PasswordCode that works only once, used as an MFA factor.
PIRPost-incident ReportingWritten review of what happened in an incident and what to change.
SAMLSecurity Assertions Markup LanguageExchanges identity assertions for federation and SSO.
SCAPSecurity Content Automation ProtocolStandards for automated security configuration checks.
SELinuxSecurity-enhanced LinuxLinux feature that enforces strict access rules on processes.
SFPSmall Form-factor PluggableSmall swappable network transceiver module.
SIEMSecurity Information and Event ManagementAggregates and correlates logs for detection and investigation.
SNMPSimple Network Management ProtocolMonitors and manages network devices.
SOARSecurity Orchestration, Automation, and ResponseCoordinates and automates security-response workflows.
SOCSecurity Operations CenterTeam or facility monitoring and responding to security events.
SPFSender Policy FrameworkDNS policy listing permitted email senders.
SSOSingle Sign-onOne login provides access to multiple connected services.
UTMUnified Threat ManagementOne appliance combining firewall, filtering and other protections.
WAFWeb Application FirewallFilters HTTP traffic to protect web applications.
WIPSWireless Intrusion Prevention SystemDetects and blocks rogue or attacking wireless devices.
XDRExtended Detection and ResponseCorrelates detection data across multiple security layers.

Domain 5: Security Program Management and Oversight

AcronymStands forWhat it means
ALEAnnualized Loss ExpectancyEstimated annual loss: SLE multiplied by ARO.
AML/CTFAnti-money Laundering/Counter-terrorism FinancingRules against moving illegal money; a common compliance training topic.
AROAnnualized Rate of OccurrenceExpected frequency of a risk event per year.
AUPAcceptable Use PolicyDefines permitted use of systems and networks.
BECBusiness Email CompromiseSocial-engineering fraud through trusted-looking business messages.
BYODBring Your Own DevicePersonal devices are allowed for organizational work.
EOIExpression of InterestEarly, informal step to see which vendors want to bid.
LMSLearning Management SystemPlatform that delivers and tracks training.
MOAMemorandum of AgreementDocuments agreed responsibilities between parties.
MOUMemorandum of UnderstandingDocuments shared intentions between parties.
MSAMaster Service AgreementUmbrella contract setting the terms for future work with a vendor.
NDANon-disclosure AgreementContract requiring confidentiality.
RFCRequest for CommentsPublished technical standard, often for internet protocols.
RFIRequest for InformationAsks vendors for general information about what they offer.
RFPRequest for ProposalAsks vendors to propose how they'd meet your requirements.
RFQRequest for QuoteAsks vendors for pricing on a defined need.
ROIReturn on InvestmentBenefit compared with cost of an investment.
SLESingle Loss ExpectancyExpected cost from one realized risk event.
SOWStatement of WorkDefines the specific tasks, deliverables and timeline for a job.
