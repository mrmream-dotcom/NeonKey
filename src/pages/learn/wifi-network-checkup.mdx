<p class="lead">Most routers get set up once, on install day, and never opened again. This guide covers the few settings that matter and what good looks like. Menu names vary, but the ideas are the same on almost any router.</p>

You don't need to be technical, just patient with a few menus.

## What you'll need

- A laptop or phone on your Wi-Fi
- Access to the router, so you can read its sticker
- A password manager, or somewhere safe to note new passwords
- About 30 minutes when a few minutes offline won't bother anyone

## Why the router is worth a look

The router is the front door to everything on your network, from laptops to cameras. It rarely nags about updates, so problems can sit quietly for years.

- Anyone who gets into it can see or redirect much of your traffic.
- Most of the risk sits in a short list of settings, covered below in order.

## Getting into the router's admin page

Every router has a settings page, the admin page. Its default password is often printed on the router itself, so check this first.

- **Find it:** the router's sticker lists an address (often 192.168.0.1 or 192.168.1.1) and a login.
- **Open it:** type that address into a browser on your Wi-Fi, or scan the QR code if it uses an app.
- **Check:** if the sticker password still works, anyone walking past can get in.
- **Fix:** change it to something long and random, saved in a password manager. This is the top fix here.

- **Provider router?** Some settings may be locked. Change what you can and ask them about the rest.

## Firmware updates

Firmware is the software that runs the router. Security fixes only reach you if updates get installed.

- **Check:** installed version, its date, and an automatic updates option.
- **Good:** a recent version, with automatic updates on.
- **Red flag:** years-old firmware with no new releases. Budget for a new router.
- **Tip:** updates restart the router; don't unplug it mid-update.

## Your Wi-Fi name and password

The Wi-Fi name is what everyone sees in their network list. The Wi-Fi password decides who can join; it's separate from the admin password.

- **Name (SSID):** drop any router brand or model, plus your name or address. Boring is best.
- **Password:** a few random words, strong and easy to type.
- **Shared too widely?** Change it, but do it last: every device must rejoin.

## Security type: WPA3, WPA2 and the pairing button

The security type scrambles your Wi-Fi traffic so people nearby can't read it. Look for it in the wireless settings.

- **Best:** Wi-Fi Protected Access 3 (WPA3), the current standard.
- **Fine:** WPA2 with a strong password.
- **Practical pick:** mixed mode (WPA2/WPA3) for a mix of old and new devices.
- **Change now:** WEP or "Open" (no password).
- **Push-button pairing (Wi-Fi Protected Setup, or WPS):** turn it off. It has known weaknesses.

## A guest network for visitors and smart gadgets

A guest network is a second Wi-Fi network that gets internet but can't see your main devices.

- **Who goes there:** visitors, plus smart gadgets like the TV and thermostat, which are often the least looked-after devices.
- **Check:** guest access to main-network devices is off.
- **Heads-up:** a gadget or two may need setting up again.

## Remote management: off unless you need it

Remote management (or remote access) opens the admin page to the internet, where automated attacks constantly try common passwords.

- **Good:** off, unless your IT person uses it.
- **Provider router?** Ask before switching it off.

## Who's actually connected

Most routers list connected devices ("clients"). The goal is to match each entry to something you own, not to panic over odd names.

- **Identify:** turn things off one at a time and watch what disappears.
- **Unknowns:** block them, or change the Wi-Fi password.
- **Tidy up:** rename devices you recognise.

## Speed, before and after

These changes aren't about speed, though some can help. A before-and-after test lets you see.

- **Fair test:** run a free speed test before and after, same device, spot and time of day.
- **What it shows:** download, upload (for video calls) and ping, the delay before data moves.
- **Read it loosely:** small differences are usually noise.
- **Far below your plan, near the router?** Ask your internet provider.

## Before you close the settings page

A checkup is a snapshot; the habit keeps your network healthy.

- Photograph each page before changing it.
- Save new passwords in your password manager.
- Set a reminder to recheck in a few months.

## Common questions

**Will changing these settings break anything?** Changing the Wi-Fi name, password or security type disconnects every device until it rejoins, so leave time.

**Do I need a new router?** Not usually. Replace it if updates have stopped, or if it can't offer at least WPA2 with a strong password.

**What if I can't log in at all?** A reset button restores factory settings but wipes everything, so use it only when ready to set up again, or ask your provider first.
