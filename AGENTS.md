# AGENTS.md (for OpenAI Codex and other non-Claude agents)

Read `CLAUDE.md` first; it is the single rulebook for this repository and applies to you in full.

Scope for outside agents: review only, unless the PR description says otherwise. Report findings as `file:line`, one-sentence problem, suggested fix. Do not push commits, open PRs, deploy, touch `workers/*` secrets or settings, or change prices, legal text or `public/CNAME`.
