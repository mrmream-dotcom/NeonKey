# Pricing notes: Remote Small-Office IT Setup & Support

Researched 2026-10-29. These are public freelance-market data points used to set **conservative starter prices**. They are not a quote and not a promise of income.

## Data points

| Source | What it says |
|---|---|
| [Upwork: hourly rates overview](https://www.upwork.com/resources/upwork-hourly-rates/) | Upwork's own guide to typical freelancer hourly rates by category (general reference). |
| [lilachbullock.com: IT virtual assistant rates](https://www.lilachbullock.com/it-virtual-assistant/) | Entry-level IT VA profiles with basic Google Workspace and helpdesk skills bill **$15–25/hr** on Upwork; mid-range with automation or platform skills **$35–55/hr**; specialists in small-business security basics (password managers, 2FA rollouts) **$60–85/hr**. |
| [Upwork job: Ongoing Support Specialist (M365, Outlook, Google Workspace)](https://www.upwork.com/freelance-jobs/apply/Ongoing-Support-Specialist-Microsoft-365-Outlook-Google-Workspace-Monday-com-SaaS-Platforms_~022110834682526270730/) | A client posting for ongoing remote SaaS support offering a **$100/month minimum for 5 hours**, plus an hourly rate for extra time. |
| [Upwork job: System Administrator, remote help for a small consulting firm](https://www.upwork.com/freelance-jobs/apply/System-Administrator-Remote-help-with-small-Consulting-Firm_~022107473656897294768/) | A small firm's remote sysadmin posting at about **$35/hr**. |

## How the starter prices were set

- **Setup: from $150, typical $150–$400.** About 3–8 hours of work at the low-to-mid end of the $35–55/hr range, depending on how many people, mailboxes and items are in scope. Sits between the existing $75–150 and $250–500 offers.
- **Monthly remote support plan: from $75/mo, typical $75–$150/mo.** In line with the real $100/month-for-5-hours posting above. Async email/ticket support, a set number of small requests, an agreed business-day response window, no 24/7.

## Caveats

- These are thin, mixed-quality sources (one blog, one Upwork guide, two individual job posts). Treat the numbers as a floor for a beginner offer, not a market average.
- If you'd rather not publish prices until you've done a few jobs, change the service copy to "Quote on request" (edit `src/data/services.ts` and `src/pages/services/remote-it.astro`).
